# Guía de Instalación VMware Workstation

Guía rápida para instalar VMware Workstation en Windows.

## Requisitos

Antes de comenzar, verifica que cuentas con lo siguiente:

- Instalador de VMware Workstation
- Windows 10 u 11

## Instalación

Descarga el instalador de VMware Workstation haciendo clic [aquí](https://drive.google.com/file/d/11PicGc8j_sct19zGqOXieOjwX8o7UfGm/view?usp=sharing).

Ejecuta el instalador utilizando la configuración predeterminada. Solo presta atención a las siguientes ventanas:

| Ventana                                     | Opción                      |
| ------------------------------------------- | --------------------------- |
| Configuración de la experiencia del usuario | Desmarcar la segunda opción |

> [!TIP]
> Al finalizar la instalación, reinicia tu equipo antes de continuar con la instalación de GNS3.
